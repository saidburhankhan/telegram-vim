# telegram-vim (Python, archived)

This repository contains the original Python implementation of telegram-vim.
It is kept online for historical reference and is no longer maintained.

The current version is written in Rust and lives at:

**[saidburhankhan/telegram-vim-rust](https://github.com/saidburhankhan/telegram-vim-rust)**

Please use the Rust repository for installation instructions, releases, bug
reports, and new development.

## Security note

Never commit Telegram credentials or local session data. Files such as
`config.toml`, `config.toml.bak.*`, `.env`, `*.session`, logs, downloads, and
the local allowlist are excluded by this repository's `.gitignore`.
